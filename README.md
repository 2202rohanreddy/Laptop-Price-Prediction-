# Laptop Price Prediction Using Machine Learning

This project focuses on predicting the price of laptops based on their specifications using Machine Learning algorithms. By analyzing features such as brand, processor, RAM, storage, GPU, and operating system, the model learns patterns to estimate laptop prices accurately.

The project demonstrates the complete machine learning pipeline, from data preprocessing and feature engineering to model training and evaluation.

# Problem Statement

Laptop prices vary widely depending on hardware and brand. Manually estimating a fair price can be difficult.
This project aims to build a machine learning model that predicts laptop prices based on technical specifications.
